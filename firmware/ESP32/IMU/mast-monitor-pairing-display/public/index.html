Recommended startup order

  1. Power the top node.
  2. Power the base bridge.
  3. Open this page in Chrome or Edge at http://127.0.0.1:8000.
  4. Click Pair base bridge, then select XIAO_BASE_BRIDGE.
  5. Click Pair / rescan top node if the top node does not show connected.
  6. Hold both IMUs still in the mounted neutral pose, then click Zero.
  7. Click Start stream. Start CSV logging only when you want to save data.
